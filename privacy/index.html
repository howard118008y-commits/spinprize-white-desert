隱私說明

說明官網瀏覽、線上訂購，以及文件工作台的身分驗證、文件權限與資料處理方式。

更新日期：2026 年 9 月 29 日

文件工作台提供 Google 登入，僅開放管理者核准的帳號。
現階段供管理者與同事使用，尚未開放客戶帳號；文件以工作台實際顯示與個別授權為準，現有內部入口仍維持原有方式。

官網瀏覽與聯絡

本官網由旋賞數位有限公司提供，使用 GitHub Pages 發布。載入頁面時，網站代管服務會接收提供網頁所需的連線資訊，例如 IP 位址、瀏覽器請求與時間。

截至本頁更新日，官網首頁未嵌入 Google Analytics、Meta Pixel 或其他第三方流量統計程式，作品預覽圖片從本網站載入。你點選 LINE、Instagram、Facebook 或作品連結後，將前往對應服務；透過信箱聯絡時，郵件會由你使用的郵件服務寄送。

線上訂購與付款

在線上訂購頁下單時，會收集聯絡人姓名、公司／店名、聯絡電話、Email、統一編號、備註、所選方案與優惠碼，用於建立訂單、聯繫、收款、開立發票及確認負責業務。訂單資料存放於旋賞數位以 Railway 代管的訂單伺服器，僅管理者可憑密碼查看。

選擇綠界或藍新付款時，卡號與轉帳資料由綠界科技（ECPay）或藍新金流（NewebPay）在其付款頁面處理；旋賞數位只收到付款結果、交易編號與金額，不接觸也不儲存完整卡號。訂單與付款紀錄依《商業會計法》等規定保存必要期間；查詢或更正方式見下方「詢問、更正與刪除」。

Google 登入會用到哪些資料

新工作台使用 Google 帳號確認身分，僅要求 openid、email、profile 基本身分範圍，不要求讀取 Gmail 信件或 Google Drive 文件。

Google 登入透過 Supabase Auth 處理，登入服務可能取得 Google 帳號識別碼、已驗證的電子郵件地址、名稱與頭像等基本個人資料。工作台以電子郵件地址與帳號識別碼比對授權名單；未獲授權的帳號也可能在登入服務建立身分資料，但不因此取得文件權限。

工作台資料與使用目的

  • 帳號與角色：儲存登入信箱、帳號識別碼、管理者／同事／客戶角色及啟用狀態，用於身分與權限管理。
  • 文件與指派：儲存由管理者加入的文件、名稱、類型及指派關係，供被授權的帳號查看。
  • 存取控管紀錄：儲存工作階段、登入／登出與帳號、文件權限異動紀錄，用於管理及查核；這不代表每一次文件下載都有獨立稽核紀錄。

資料由哪些服務處理

Google 提供身分驗證；Supabase 提供工作台的登入服務、資料庫及私有檔案儲存；GitHub Pages 提供網站前端。管理者可管理帳號與文件指派，同事可查看內部共用文件，客戶只可查看被明確指派的文件。

你可分別查閱 Google 隱私權政策、Supabase 隱私權政策及 GitHub 隱私權聲明，了解各服務本身的資料處理方式。

登入狀態、停用與已下載文件

新工作台的目前分頁登入狀態存放於瀏覽器 sessionStorage，工作台每次登入最長使用 1 小時，之後須重新登入。關閉分頁、登出或停用帳號，不等於刪除伺服器上的帳號、文件或紀錄。

管理者停用帳號或移除文件授權後，後續存取將依更新後的權限判斷；已開始傳輸、已在瀏覽器顯示或已下載的文件副本無法收回。

詢問、更正與刪除

若要詢問資料使用方式、更正帳號資料，或請求刪除與你相關的工作台資料，請寄信至 howard118008y@gmail.com。旋賞數位會先核對身分與資料範圍，再說明可處理的內容；目前未設自動刪除排程，也未訂定統一的資料保留天數。

Google、Supabase 或 GitHub 自身的帳戶、系統紀錄及你已下載的副本，不會因刪除工作台帳號而一併消失。
